Privacy policy

Effective 2026-11-11, for OPBS 0.6.119 and later.

No telemetry

OPBS has no analytics, no usage reporting, no accounts and no crash reporting. RHITCS does not receive information about you, your machine or your backups. Nothing in the app sends backup contents, file names, partition layouts or settings anywhere.

Network connections the app can make

OPBS is an offline-first program. The following requests are the complete list of connections it can initiate on its own:

  • Update check. If Check for updates on startup is enabled (the default), the app asks the GitHub releases API for the latest release of bobeire/opbs. As with any HTTPS request, GitHub sees the requesting IP address and user agent. The check can be turned off in Settings; the manual Check for updates button still works.
  • Downloading an update. Only after you accept an update prompt. The installer is downloaded from GitHub Releases.
  • WinFsp runtime install. When you choose Install WinFsp, the app downloads the MSI published by the WinFsp project on GitHub and runs it after a UAC prompt. Nothing about you is sent beyond the request itself.
  • Windows ADK and Node.js runtime install. When you choose those options, the installer is downloaded from Microsoft or from nodejs.org respectively.
  • Destinations you configure. S3, SFTP, network shares and webhook notifications are contacted only when you configure them. Their credentials are stored locally in your settings file and are sent only to the service you named.

Data kept on your machine

Settings, logs and backup job metadata live in your user profile; images live wherever you choose to write them. Removing the app and its data directory removes them. Backups you created are yours and are not touched by an uninstall.

Third-party services

GitHub hosts the source, releases and update checks; Microsoft supplies the Windows ADK; the OpenJS Foundation hosts Node.js. Those services have their own privacy policies. No other third party is involved.
