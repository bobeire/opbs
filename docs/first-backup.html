Make your first backup

One good backup, made today, is worth more than a perfect plan you were going to get to. Here is exactly what to click, and the three decisions that actually matter.

Before you start

Close your browser and anything else that is open and writing files. A backup of a running Windows captures a crash-consistent state — the same one a power cut leaves behind — not a clean shutdown. Anything an application was writing at that moment can come back unusable after a restore. Documents and closed applications are fine.

  1. Install OPBS and open it

    From the download page — the installer or the portable exe, same program. No account, no sign-in. You will be asked to allow it to run with administrator rights: it needs them to read disks and write images.

  2. Click New Backup

    The wizard asks four things in order: what to back up, where to put it, how to do it, and a confirmation page before anything is written.

  3. Choose what to back up

    Pick the disk that Windows runs from and select its partitions. On a normal machine that is the small boot partitions plus the large one holding Windows and your files — usually four partitions on a modern PC.

    Not sure which disk? The wizard shows the model and size. The one with your Windows install is the one with more than one partition and a large C:.

    Selecting the whole disk is the safe default. A restore then puts the machine back exactly as it was, including the bits Windows needs to start. Selecting only one partition is for when you know precisely what you are doing.

  4. Choose where to put it

    This is the decision that decides whether the backup helps you. Put it on a different physical disk — an external drive, a second internal disk, a network share.

    A backup on the same disk as the data does not protect the data.

    If the disk dies, it takes the backup with it. If you only have one disk right now, make the backup anyway and copy it somewhere else as soon as you can.

  5. Set the options

    The confirmation page lists everything. Three are worth changing from the default; the rest can wait until you are curious.

    Option What to do Why
    Verification Turn it on Reads the image back and checks it. Takes longer. Catches the failure that would otherwise only show up on the day you need the backup.
    Used data only Leave it on Skips empty space, so the image is much smaller and faster. Free space cannot contain anything you need.
    Encryption Only if the drive leaves the house Protects the image if the drive is lost or stolen. If you set a passphrase and forget it, the backup is unreadable — there is no recovery.

  6. Read the summary, then click Start Backup

    Nothing is written before this point. The summary shows the source, the destination, the compression, and whether verification is on. If any of it is wrong, use Back.

    You will see live progress with a speed and an estimate. A first backup of a typical Windows install takes tens of minutes to a couple of hours depending on how much is on the disk and how fast the destination is.

  7. Check that it worked

    When it finishes, the Dashboard shows the new backup under Backup Count, and the destination has an .opbs file in it. If verification was on and the backup completed, the image is known-good at the block level.

    That is the point at which most people stop. Do the next step instead — it is the one that turns a backup into a way out of trouble.

  8. Make recovery media

    Open Recovery Media and write it to a USB stick you will not repurpose. This is what you boot from if Windows will not start — and without it, a backup on an external drive is a file you cannot open.

    Keep the stick with the drive. The most common failure in a real emergency is not a bad backup — it is a backup in a drawer and no way to boot the machine to reach it.

What happens next

Backups are not one event. Here is the smallest routine that actually protects you.

  • After the first full backup, use incrementals. They capture only what changed, so they are fast and small.
  • Keep more than one. A single backup can be the one that caught the problem you are about to have.
  • Close applications before a backup you may restore in place. That is the one case where an application's files can come back unusable.
  • Schedule it if you will not remember. Schedules run the same backup unattended.

Honest limits

  • This is an image, not a file sync. OPBS captures whole partitions. You can browse and pull single files out of an image afterwards, but it is not a replacement for copying a folder to cloud storage.
  • A live backup is crash-consistent, not application-consistent. Closing applications first is the mitigation.
  • Windows only. There is no macOS or Linux version.
  • A backup you have never restored is a hope, not a plan. OPBS can prove restores work for you — see Prove it.
