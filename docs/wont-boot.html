Guide · for when it matters

My PC won't start

Nothing here is urgent enough to rush. The order below is the order that loses the least — read it once before you change anything.

Stop before you reinstall Windows.

Reinstalling, "resetting" the PC, or letting a repair tool repartition the disk will overwrite the very thing you are trying to recover. If someone is about to do any of those, stop them.

What you need

  • Your backup — the .opbs file on the external drive or network share where you put it.
  • The OPBS recovery USB — the stick you made after the first backup.
  • If you never made the stick: make one on any other Windows PC that can run OPBS. It does not have to be the broken machine. Open OPBS → Recovery Media and write it to a spare stick.

Step 1 — Boot from the recovery USB

  1. Plug in the stick and turn the machine on

    Press the boot-menu key while it starts. Which key depends on the machine — Esc, F12, F10, F2 or Del are the common ones, and it is usually shown on the first screen.

  2. Pick the USB stick from the list

    It may appear as the stick's name, or as "UEFI: …". Choose the UEFI entry if there are two.

    No USB entry in the boot menu?

    Some machines do not add removable drives to the menu. Use Boot from File instead (often in the same menu, or in the firmware setup), then browse to \EFI\BOOT\BOOTX64.EFI on the stick and select it. That file is the bootloader; running it starts OPBS's recovery environment exactly as the menu entry would.

  3. Wait for the OPBS Recovery menu

    The first minute is device initialisation and can look like nothing is happening. It is not stuck.

Step 2 — Decide what you actually need

Two very different jobs. Do not do the second one if the first one is what you want.

If you want… Do this Time
Your files back Option 1, then browse the image and copy files out. Nothing is overwritten. Minutes
The whole machine as it was Option 1, restore the partitions you backed up. Tens of minutes to hours

Step 3 — Get your files back, without restoring anything

Safest option first. Nothing on the broken machine is touched.

  1. Choose [1] Restore this machine from a backup image

    The wizard will ask for an image. Point it at your backup on the external drive — the recovery environment gives drives different letters than Windows did, so look for the drive by size and name rather than assuming D:.

  2. Browse the image instead of restoring

    Open the image and you will see the partitions it contains, and the files inside them, exactly as they were. Copy what you need onto another drive — a different one from the backup.

  3. Copy out what matters first

    Documents, photos, the desktop, browser profiles if you want your bookmarks and passwords. Then, if you want the machine back, come back here and do the restore.

Why files first

A restore overwrites the target. If anything about the backup or the target is not what you expected, having the important files already out means the mistake costs you nothing.

Step 4 — Restore the whole machine

  1. Choose [1], pick the image, then pick the partitions

    Restore the same partitions you backed up — usually all of them. The wizard shows the captured layout and where each partition will land.

  2. Keep verification on

    It checks each block against the checksum stored in the image as it writes. On a day like this you want to know, not hope.

  3. Read the confirmation, then let it run

    The target is overwritten. Everything else is left alone. The screen shows progress and speed throughout, and it stays open at the end — including any warnings — before the machine restarts.

  4. Take the USB stick out when it restarts

    The menu's [4] Reboot asks you to do this and waits for you. If the stick is still in, the machine boots the recovery environment again instead of Windows.

What you may see on the first boot back

Windows may say "Restart to repair drive errors" and run a disk check. If the backup was taken from a running Windows — which is normal — the image carries NTFS's dirty flag and Windows wants to repair what it sees. That prompt is the live capture, not the restore.

The repair can also discard files that were being written when the backup was taken. That is why closing applications before backing up matters.

If it still won't start

  • Try the boot menu again. After a restore the firmware sometimes keeps booting the old entry. Re-select the internal disk.
  • Check the restore finished. Reboot the USB and look at the report OPBS leaves — the recovery run's log is preserved on the restored drive and shown when OPBS next starts.
  • A missing boot partition is a common cause. Restoring only C: does not repair the small partitions Windows starts from. Restore those too if you backed them up.
  • Your files are not gone. If the machine will not boot but you got here, Step 3 still works: browse the image and copy out.
